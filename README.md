# ES File Renamer

Renomeador de arquivos que funciona diretamente no navegador, sem instalação.

🔗 **Acesse a ferramenta:** https://epitaciosouza.github.io/es-file-renamer/

## Funcionalidades

- Seleção de arquivos ou pasta de origem
- Ordenação automática por data
- Renomeação com sequência numérica
- Substituição de partes do nome
- Definição de nome-base, prefixo e sufixo
- Inclusão de carimbo de data
- Prévia dos novos nomes antes da execução
- Pasta de saída persistente
- Tema claro e escuro
- Contador público de acessos

## Como utilizar

1. Abra a ferramenta pelo link acima.
2. Configure a pasta de saída em **Configurações**.
3. Selecione uma pasta de origem ou carregue os arquivos.
4. Defina as opções de renomeação desejadas.
5. Confira o resultado em **Teste da renomeação**.
6. Clique em **Renomear arquivos**.

## Privacidade

O processamento dos arquivos é realizado localmente pelo navegador. Os arquivos não são enviados para o GitHub nem armazenados em um servidor.

O contador registra somente a abertura da página e não recebe o conteúdo dos arquivos selecionados.

## Compatibilidade

Para selecionar pastas e manter a autorização da pasta de saída, utilize uma versão atualizada do Google Chrome ou do Microsoft Edge.
